# ANILA 全站介面檢視

日期：2026-09-14。環境：https://172.16.120.153；目前登入角色為 admin／擁有者。

本次逐一開啟治理中心全部 20 個主要導覽頁面，另檢查知識庫明細、ANILA 對話端、平台入口、專案入口與設定的五個頁籤。以實際桌面畫面、DOM 語意及唯讀互動為證據。沒有提交帳號、權限、公告、憑證或模型設定變更，也沒有發送新對話。

這是全站可見頁面的介面盤點，不是所有角色、所有資料狀態、所有彈窗與後端功能的完整驗收。未讀原始碼，未確認框架、設計 token、部署 SHA。以下位置以頁面與元件定位。
