## 四、每一包留下什麼要長期照顧的

`PLAN.md` 現在把這個列為**收貨條件**（擁有者 08-05：「要新增也可以，但重點是系統不要越來越複雜」）。

**健康總覽** — 四個「假設住在兩個地方，只有一個被測試看著」：arq 的健康鍵字串（釘的是我們的漂移，不是 arq 的）；TTL 與阻塞表是**同一個保證**，而**沒有東西守著那張表**（它是人工稽核，會腐）；「容器停掉立刻轉紅」**完全建立在 docker DNS 不解析未執行容器**這個環境事實上（換 k8s 就靜默降級）；`PDF_OCR_FALLBACK` 一個旗標把餘裕從約 40 倍砍到約 2 倍。

**CSRF** — 🔴 **最重要的一條**：出貨的版本上 `request.url.path` **就是** `scope["path"]`，所以這裡每一條靠 Host 的測試在語意上都是空的。**撐住六個安全判斷可觀測性的，是一個刻意做作的公開屬性替換。** 哪天有人覺得那些夾具很假而刪掉，六條線安靜地回到沒有測試，而**只有把 starlette 降版才會發現**。（`routed_path()` 的 docstring 就是講這件事的，它現在是承重的。）

**RAG** — 文案守衛只擋**原樣貼回**，不擋說謊；三個已知繞法有名字、有測試釘住。anilalm **沒有 CI**。設定檔拆成兩份，vitest 是**取代**不是合併 vite config。

**索引錯配** — PG-only 的測試套件**沒有連線字串就整批跳過**，所以那段 SQL 在預設執行裡是隱形的；大小寫比對是**資料缺陷的權宜之計**，而缺陷還在（#56 九條清單）。

**PII／拆遮罩** — 🔴 **隱私分頁那兩顆按鈕不可以改成條件渲染**。那是全平台唯一能改這個長期設定的入口；改成有條件顯示，等於把使用者鎖在門外（08-05 實際發生過一次）。`ui_settings` 是**整包取代**，寫第三個 key 會在下次存檔被洗掉（今日無實害，只有兩個 key）。

**憑證偵測** — 🔴 **`BLOCKING_FAMILIES` 是那個檔案裡最扛事的一行。**
所有規則都會衰退，而且是兩個方向各自衰退：

- **負空間判斷**（案號不會剛好帶合法檢查碼、預算欄是 tab 貼的不是空格、沒有人在 `password:` 後面寫八個無意義英數）——
  **每一條今天成立，都只是因為現在的表單剛好長那樣。表單一改就不成立，而且不會大聲壞掉**，
  它會一次一個樣本地重新喊狼，直到那條橫幅變成壁紙。
- **廠商前綴**（`sk-`／`ghp_`／`AKIA`）沒有穩定性保證 →
  **這份清單會安靜地對新的金鑰格式失明，而且看起來跟今天一樣健康。**

**兩種衰退之所以可以承受，唯一的理由是「憑證不能擋人」**——代價是一條白跳的橫幅，

`credentialDetect.test.jsx` 的語料是這些假設**唯一被寫成可檢查事實**的地方——
誰改了表單、文件編號規則或廠商金鑰格式，**動正規式之前先把樣本加進去**。

### 這三包留下什麼要長期照顧的

**DOCX** — 耐久解是**計數器而不是順序契約**：這個 parser 家族反覆出的錯是「內容不見了而沒人被告知」（巢狀表格、頁首頁尾、`w:sdt`、`w:ins`、ODT 同型）。現在每份文件會記一則彙總警告，但**得有人真的讀到那個數字**——沒人在批次上傳時盯 worker log，真正的終點是掛到 ingestion job 紀錄上（schema 變更，屬 job model 擁有者）。

**ALLOWED_HOSTS** — 🔴 放行集原本有**六份手抄本**，現在五份被機器對帳（compose 是唯一真相，`.env.example`、runbook ×2、測試字面都會因為 compose 改動而轉紅）。**剩下 nginx 的 `$is_anila_host` map 是最後一份靜默副本，而且它會先腐**——因為兩個集合**刻意不相等**（csp 多 `csp`、少 `10.53.100.12`），任何人改一邊都得**重新推導**那個差異，不是複製貼上。

**部署衛生** — 掃描器現在有自我測試當正控制（規則被刪光、白名單長歪、抽檔沒做完都會大聲死），但它**抓不到「與任何 fixture 都不重疊的放寬」**（例如有人加 `*/node_modules/*`）。另外它**掃不到映像的 ENV／history 層**——檔頭誠實列著這件事，實測確認一個種在 `ENV` 裡的祕密它看不到。
