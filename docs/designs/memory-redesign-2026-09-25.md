# 長期記憶重新設計（2026-09-25）

> 狀態：方向已定（擁有者 2026-09-25 同意 1～5），待實作。
> 相關：`services/csp/app/services/memory_service.py`、`packages/anila-core/src/anila_core/memory/long_term/`、模型角色（`summary`）。

## 1. 現況與證據

每一輪對話結束後，會在背景做兩件事：
1. 把**使用者訊息**和 **AI 的完整回答**各自存成一段記憶並做向量化（`conversation_memory_chunks`）。
2. 呼叫一次 LLM，從這一輪萃取「個人事實」（`user_facts`）。

每次發問時，用這一句去比對相似度，找出最相近的 top-k 段（預設 3 段、門檻 0.4、每段最多 1200 字、總長 4000 字），連同事實一起放進 system prompt 最前面的「過往相關討論」。

**活體實測（admin 帳號，deepseek-v4.1-flash）**

| | 自動附上記憶（門檻 0.4） | 關閉（門檻 1.0） |
|---|---|---|
| 「幫我做一份報告」的反問，思考時間 | 159～175 秒 | 1～3 秒 |
| 「ANILA 的系統架構是什麼？」 | 逐字照抄先前洩漏的回答（「隔離內網」、vendor 路徑） | 使用者層級的說明，沒有洩漏 |

**問題**
1. **AI 的回答被當成記憶餵回去。** 錯誤的回答、洩漏的內容、錯誤訊息都會被存下來，之後遇到相似的問題就被拿出來照抄。
2. **每一輪都自動附上。** 相似但無關的舊對話拖長了思考時間，並讓回答被舊內容綁住。
3. **萃取用的模型是隨便挑的。** 設定的 `MEMORY_LLM_MODEL=gemma4` 不存在，程式就退回「第一個啟用的 LLM」。admin 的「已知事實」目前是空的。
4. **每一輪多打一次 LLM**，卻沒有產出任何事實。
5. 檢索只看相似度，不看時間新舊，也不去除重複。

## 2. 參考做法

- **ChatGPT**：只存濃縮過的事實和偏好，使用者可以查看、刪除；不存對話原文。
- **Claude**：有少量固定的記憶；過去的對話由模型在需要時自己去搜尋，不會每一輪都自動塞入。

## 3. 新設計

1. **不再存 AI 的回答原文。** 只保留兩種記憶：
   - **事實與偏好**：短句，例如「使用者在雷達組、偏好條列」。
   - **對話摘要**：每段對話一則，由 `summary` 角色的模型產生，只描述使用者要什麼、得出什麼結論，不含 AI 原文。
2. **每一輪固定附上的只有事實與偏好**，總長度設上限。使用者可以在畫面上查看、修改、刪除；admin 可以停用整個功能。
3. **過往對話改成需要時才搜尋。**
   - Router prompt 告訴模型有一個「搜尋過往對話」的能力。模型判斷需要時（例如使用者說「延續上次」「之前那份報告」），才對**對話摘要**做檢索，再把結果帶入。
   - 實作可以用 Router 協定裡的一行標記（例如 `RECALL: <查詢>`），比照 DISPATCH／ASK 的處理方式，由 Router 解析、檢索、再開一輪。
4. **萃取時機與模型**
   - 在對話閒置一段時間後、或使用者開新對話時，萃取一次（摘要與事實一起產出），不是每一輪都萃取。
   - 使用 Console 的 `summary` 角色。角色沒設定時就不萃取，並在 Console 顯示警告，不再隨便挑一個模型。
   - 只萃取使用者自己陳述的事實，不把 AI 說的話當成事實。
   - 失敗、救援、錯誤訊息的回合不萃取。
5. **清理現有資料**
   - 用 migration 刪除 `conversation_memory_chunks` 中 `role='assistant'` 的列。
   - 擁有者決定（開發階段、沒有使用者）：新版上線時直接清空所有舊的記憶片段與事實，不轉換、不保留。

## 4. 影響範圍

| 元件 | 改動 |
|---|---|
| CSP `memory_service.py` | 拿掉每一輪存 AI 回答與萃取；新增對話摘要的產生與檢索；萃取改用 `summary` 角色 |
| CSP API／migration | 對話摘要表（或沿用 chunks 表加上 `kind='summary'`）；清掉 AI 回答的片段 |
| Router | 固定只附上事實與偏好；新增 `RECALL:` 協定與檢索回合；prompt 規則 |
| Shell | 「記憶」頁：列出事實與偏好，可以修改、刪除；顯示「已搜尋過往對話」的階段 |
| Console | 記憶功能的總開關；`summary` 角色沒設定時顯示警告 |

## 6. 驗收

- 同一個「幫我做一份報告」，在有大量舊對話的帳號上，反問的思考時間跟新帳號相同等級（數秒）。
- 舊的錯誤或洩漏回答不會再出現在新的回答裡。
- 使用者說「延續上次那份報告」時，會出現「搜尋過往對話」階段，並正確帶出上次的結論。
- `summary` 角色沒設定時，不會萃取，Console 會顯示警告。
