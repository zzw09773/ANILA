# ANILA 使用者說明（初版）

> 對象:平台的一般使用者。內容只寫**目前這個版本真的做得到**的事。
> 每一節都標了「UI 路徑」,你可以自己按一次確認 —— 如果按不到,那是文件錯了,請回報。
> 管理員 / 開發者的操作在 `docs/guides/developer-guide.md`,不在本檔。

平台內也有同一份摘要:頂欄的 **說明** 鈕(或按 `⌘/` 或 `Ctrl+/`)。
面板的章節標題與本檔一致,並由前端測試逐章節比對,避免兩邊說不一樣的話。

## 開始使用

UI 路徑:登入後的主畫面(任務中心)。

三步:

1. **選一個 agent。** 輸入框上方的 `target:` 就是要回答的人。預設是 **ANILA Router**,
   它會自己判斷「直接回答」或「派給合適的 agent」。想直接指定某個 agent,在輸入框打 `@`
   再從清單選名字。
   * UI 路徑:輸入框上方的 agent 下拉選單;或輸入框內打 `@`。
2. **上傳你的知識庫。** 要問「這份文件裡寫了什麼」,先把檔案放進知識庫,不要只丟到聊天視窗。
   * UI 路徑:側欄 →「我的知識庫」→ 建立知識庫 → 上傳檔案。
   * ⚠ 聊天視窗的附件目前**只有圖片**會真的被模型看到;非圖片檔案只會把**檔名**帶給模型,
     模型看不到內容。要問文件內容一律走知識庫。
3. **直接問。** `Enter` 送出,`Shift+Enter` 換行。回答下方會列出引用來源,點下去可以看到
   它引用了哪一份文件的哪一段。
   * UI 路徑:輸入框;回答下方的引用標記 → 右側引用抽屜。

首次登入時主畫面會出現一張三步導引卡,按「知道了,不用再顯示」之後就不會再出現。
要再看一次,按頂欄的 **說明**。

## 密等鎖定（latch）如何運作

UI 路徑:對話頂欄的「密等鎖定」標記與五級密等徽章;設定 → 一般 / 隱私 · 信任。

* 密等**由後端決定**,不是使用者的偏好。兩個來源:
  1. 這個 agent 被管理員標記為 `requires_encryption`(欄位名沿用歷史命名);
  2. 回應的 meta 判定這次對話應升密。
* **鎖定是單向的。** 一旦升級,使用者無法在該對話退回,UI 上沒有任何解除開關 —— 這是刻意的。
* **「密等鎖定」不等於加密。** 平台**不對訊息內容做靜態加密**(no at-rest encryption)。
  鎖住的是「能不能帶出去」與「留不留紀錄」,不是把內容變成密文。
  舊版 UI 把這個機制寫成「加密」,那個說法是錯的,已於 2026-07-26 更正措辭。
  若你的簡報 / 教材沿用舊字眼,請一併更正。
* 對話因為引用了已鎖定密等的過往記憶而升級時,畫面上方會出現橘色橫幅說明原因。
  * UI 路徑:對話上方的繼承橫幅。

## 複製與匯出限制

UI 路徑:訊息下方的複製鈕、側欄對話的「⋯」選單(匯出 Markdown / JSON)、頂欄的分享鈕。

**規則:**被鎖定密等的對話不得以任何形式帶離平台 —— 包含複製貼上、匯出檔案、分享連結、
截圖與列印。

**目前 UI 實際做到的攔阻:**

| 動作 | 對話已鎖定密等時 |
|---|---|
| 複製訊息 | 複製鈕不出現 |
| 匯出 Markdown / JSON | 匯出選項不出現 |
| 建立分享連結 | 分享鈕停用,tooltip 說明原因 |
| 畫面浮水印 | 顯示使用者身分與 trace 的稽核浮水印 |

**為什麼要這樣管:** 密等鎖定是單向的,而複製 / 匯出 / 分享 / 列印是**唯一**能把內容帶離
平台的路徑。如果外流面不跟著密等一起收緊,分級就只是一個顏色標籤,不構成控制。浮水印的用途
是讓帶出去的畫面**留下可追溯的紀錄** —— 它擋不住有心人,但會讓事後追查得出來是誰。

需要正式送出內容時,走公文 / 正式交付流程,不要用截圖或複製貼上繞過。

## 記憶功能

UI 路徑:設定 → 記憶。

* 長期記憶是**部署層的旗標**(`ENABLE_MEMORY`),不是個人偏好,使用者無法自行開關。
* 沒開的部署:平台**不會**從你的對話萃取事實,也**不會**建立跨對話語意索引;
  設定 → 記憶會直接寫「本部署未啟用記憶功能」。
* 有開的部署:每輪對話後會把可能長期有用的事實存成 key/value,並把訊息向量化以便跨對話檢索。
  資料只屬於你個人,不與其他使用者共享。
* **不論有沒有開**,設定 → 記憶都能看到既有紀錄,並逐筆刪除或整批清空。
  旗標關閉不會沒收你的刪除權。
* 需要啟用 / 停用,請聯絡管理員。

## 鍵盤快捷鍵

UI 路徑:頂欄 **說明** 鈕,或直接按 `⌘/` 或 `Ctrl+/`。

下表是目前這個版本**真的可用**的按鍵。

| 按鍵 | 作用 |
|---|---|
| `Enter` | 送出訊息(注音／拼音組字中按 Enter 是選字,不會誤送) |
| `Shift+Enter` | 換行,不送出 |
| `⌘/ 或 Ctrl+/` | 開啟／關閉說明面板 |
| `⌘Enter 或 Ctrl+Enter` | 編輯自己的訊息時儲存並重新產生 |
| `Esc` | 取消編輯、關閉面板、清空側欄搜尋 |
| `@` | 在輸入框叫出 agent 清單 |
| `↑ / ↓` | 在 @agent 清單中上下移動 |
| `Tab` | 選中 @agent 清單目前的項目 |
