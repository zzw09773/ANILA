# 助手快製：單位審核者手冊

主管從治理中心「助手快製」`/quick-builder` 審核所屬權限範圍的助手。核准對象是送審的特定版本；主管核准後，建立者還須註冊為 Agent，由既有平台管理員核准才能使用。正式驗收結果另記在[驗收表](quick-builder-acceptance.md)。

## 審核前準備

1. 以本人院內憑證卡登入 AI 平台，確認所屬單位與單位管理權限。主管權限沿用既有平台的人資或管理員指派，不在快製平台另建。
2. 請建立者提供助手名稱、送審版本及測試案例。審核使用去識別或經核准的資料，避免為了審核而下載整份差勤紀錄。
3. 確認自己不是助手建立者。建立者即使有主管或管理員權限，也不能自行核准；應由另一位有權限的主管審核。

## 審核差勤查詢助手

1. 進入「助手快製」，選擇助手，再開「版本與審核」。在「檢視版本」選待主管審核的版本，核對版本號及建立者提供的資料。
2. 查看該版本的助手名稱、用途、模型、密等及開放範圍。一般差勤查詢先採「本單位」；要開放指定單位或全院，需確認資料來源與一般使用者的權限同時適用。
3. 查看流程與工具設定：只能使用管理員核准的查詢工具；不得有送出申請、修改差勤、預約或其他寫入動作。查詢條件不能將建立者或系統帳號當作每個人的身分。
4. 到「測試對話」確認同一版本，核對測試結果與逐步紀錄。測試身分是目前登入者，因此主管本人試跑不等於一般同仁已通過隔離測試；另請兩名測試人員各自登入驗證本人資料。
5. 核對無資料、無權限、工具中斷、逾時等情況能以白話回報，且留下錯誤類型。逐步紀錄應遮罩憑證與敏感資料。
6. 若需要調整，在「審核說明」寫具體原因後按「附理由退回」，例如開放範圍不符或工具選錯。建立者修改後須另存新版本再送審。
7. 符合要求時按「核准這個版本」。核對回應成功、版本狀態與稽核紀錄；核准不會直接使尚未註冊的助手出現在 ANILA。
8. 通知建立者依[建立者手冊](quick-builder-creator.md)註冊核准版本，再請平台管理員完成既有 Agent 核准。記下實際上架版本，並請一般同仁在 ANILA 對話確認。

## 審核規章問答助手

1. 核對文件集有明確單位歸屬，且已由平台管理員在「管理文件集開放範圍」採管；個人庫不能直接公開供助手使用。「本單位」只適用文件集所屬同一單位，不因主管可管理下層單位而自動開放。來源應是有效的核定規章，並檢查個資或其他不適合開放的內容。
2. 以條號、規章名及一個實際問題試跑。展開檢索片段，與原檔核對答案、檔名及頁碼；簡報看投影片編號，程式碼看行號。
3. 針對掃描件抽查繁體中文、表格與頁碼。解析成功不代表文字辨識正確，OCR 品質要用單位實際語料確認。未成功處理的文件不能列為回答依據。
4. 詢問文件沒有載明的問題，核對助手不將猜測寫成規定；草稿輸出仍由人員確認後使用。文件草稿可設定純文字 RTF 或四種固定 Studio 版型的 HTML／PDF／DOCX；Studio 只排版前一步內容，不再叫模型或 RAG。核對標題、版型、格式、本人服務權限與成品。四版型乘三格式的離線轉檔 12 組已有工程證據，仍需院內正式串接與實際內容審查，不能視為任意 Office 範本套用。
5. 公開助手不等於公開文件集，儲存助手也不能變更文件集 ACL。文件公開須平台管理員另行核准；若文件仍為單位限定，其他單位的提問者不得取得文件片段、原文或原始逐步紀錄。檢查來源採管範圍與助手開放範圍各自符合核准用途。
6. 依差勤流程第 6–8 步退回或核准，完成 Agent 註冊與平台核准。

## 新版與舊版的核對

| 情況 | 應確認的結果 |
|---|---|
| 已送審第 2 版，建立者又儲存第 3 版 | 審核仍鎖定第 2 版的完整內容及雜湊；第 3 版不能偷換核准內容 |
| 第 2 版退回 | 保留退回理由；已發布第 1 版持續運作 |
| 第 2 版主管核准、已註冊 Agent，但平台尚未核准 | ANILA 仍使用已發布第 1 版 |
| 平台管理員核准第 2 版 | 線上指向第 2 版，舊 Agent 不再作為可用版本 |
| 回復舊版 | 另建新草稿並重新走測試、主管審核與 Agent 核准 |
| 模型、文件集或工具被撤權／停用 | 每次執行重新檢查，不能因舊版曾核准就繼續取用 |
| 助手停用 | 快製平台與 AI 平台同步拒絕使用；檢查快取或既有對話不得繞過 |
| 停用後恢復 | 另存晚於停用記錄的新版本，重新主管審核、註冊及平台核准；舊候選不可重新核准 |
| 一般 Agent 頁修改或刪除快製 Agent | 管理護欄拒絕；內容變更走快製新版本，下架走停用 |
| 文件產出後原任務／對話升密 | 重新檢查有效密等，清除不允許的產物並拒絕下載；不能靠舊網址繞過 |
| 公開來源撤回 | 一般使用者不再看到引用該來源的自訂範本，既有助手每次仍重檢來源 |

採管文件集的上傳、修改與刪除權不同於查詢權，除平台管理員外，只限仍在精確所屬單位的文件集建立者。審核時不得將跨單位可讀解讀為可修改來源。

## 審核留存

保留助手與版本識別、審核人、時間、決定與理由、資料來源、測試案例及發布後確認結果。建立、儲存、送審、退回、核准、註冊、發布、執行、停用均應能在既有稽核查詢核對；可由管理員匯出保存，保存期限依院內規定。若畫面版本、稽核與 ANILA 實際版本不一致，先暫緩該版本上架並交由維護人員釐清。
