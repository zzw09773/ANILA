# 助手快製：第一期驗收表

本表依《AI 助手快製平台需求規格書》第一期 FR-01–18、DS-01–15 及 NF-01–16 編排。表列「待驗」表示尚未附正式驗收證據；程式存在、單元測試通過、合成資料或替身服務演練都不能直接改填正式通過。第二期排程、事件觸發與寫入工具不在第一期範圍。

## 紀錄方式與測試資料

每次驗證記錄出貨版本、原始碼提交、遷移 head、環境、測試日期、操作者角色、案例識別、輸入、預期與實際結果、證據位置及缺陷。證據不含真實金鑰、完整 JWT 或不必要個資；需要敏感資料的報告依院內權限保存。

準備 A、B、C 三個需求單位；各有建立者、另一位主管與一般同仁，另有平台管理員。至少兩位同仁有不同的本人查詢結果。準備單位私有與公開文件集、核准唯讀 MCP、未核准及寫入型工具，以及有效、過期、錯誤 audience 的測試憑證。正式案例使用院方授權的去識別或實際資料。

狀態由院方驗收人員依證據填「通過／不通過／待驗／待確認」。合成測試另記「工程測試」及限制，不代替真實服務、真實瀏覽器、弱掃、離線交付或三單位 PoC。

## 仍須核定的數值與範圍

正式公開是否另需核准、平台端核准責任、共用資料夾同步、MCP 資料庫種類、平台延遲目標、文件總量與單檔上限、OCR 資源、保固與修補時效、教育訓練場次／時數、PoC 使用期間及時程預算，由院方確認。現行操作以既有 Agent 平台管理員核准為必要門檻。
