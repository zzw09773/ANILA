# 決策紀錄

一行一條：日期、決定、原因。只記會影響之後怎麼改的取捨；細節看連到的程式或 [`CURRENT-STATUS.md`](CURRENT-STATUS.md)。派工時附上相關的幾條。新的決定加在最下面，推翻舊決定時另寫一條，不改舊的。

這份是公開 repo 的一部分：不寫院內位址、主機名、人資資料表或欄位名，也不寫任何人的個人資料。
