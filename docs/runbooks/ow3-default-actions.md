# 建立三顆預設訊息按鈕

> 對象：平台擁有者或開發者。約 5 分鐘。
> 翻譯、摘要、公文這三顆按鈕由伺服器管理，有權限與稽核。建立之前，使用者的訊息列上不會有任何自訂按鈕。

## 誰能做

| 動作 | dev | admin+ | owner |
|---|---|---|---|
| 建立 | ✅ | ✅ | ✅ |
| 修改／刪除／指派誰能按 | ✅ 限自己建的 | ✅ 任何一筆 | ✅ |
| 稽核匯出 | ❌ | ✅（IP 與 metadata 遮蔽） | ✅ 完整 |

## 步驟

1. 進治理後台 → 側邊欄「自訂動作」。
2. 「新增動作」，照下方三份範本各建一顆（面板上的「需要自由輸入」對應 schema 的 `input`，勾了才會出現「輸入標籤」欄）。
3. 每顆建完按「綁定」→ 指定誰能按（角色／部門節點／指定人）。
   ⚠ **零綁定 = 除了作者自己，沒有其他人看得到**（fail-closed 設計；建立者在自己的訊息列上仍看得到他建的動作）。部門綁定涵蓋該節點以下整棵子樹。
4. 請一位被指定的使用者重整 ANILA，訊息列上就會出現該 icon。

## 三份範本

模板裡可用三個佔位字串：`{content}`＝這則 AI 回覆的內文、`{choice}`＝使用者選的項目的 prompt、`{input}`＝使用者當場輸入的文字。**沒有其他佔位字串會被代換**，訊息內文裡出現的大括號會原樣保留。

### 1. 翻譯

- 名稱 `translate`／標籤 `翻譯`／圖示：任選，但要出自伺服器 allow-list（面板清單來自 `GET /api/message-actions/icons`）
- 內容：

```
請將以下內容翻譯成{choice}，只輸出譯文，不要加說明：

{content}
```

- 選項（choices）：
  - `en` / 英文 / prompt：`英文`
  - `ja` / 日文 / prompt：`日文`
  - `zh` / 繁體中文 / prompt：`繁體中文（台灣用語）`

### 2. 摘要

- 名稱 `summarize`／標籤 `摘要`
- 內容：

```
請用條列式摘要以下內容的重點，最多五點，繁體中文：

{content}
```

- 選項：留空（零選項時點 icon 仍會開面板，面板裡只有「送出」與「查看將送出的內容」；沒有選項清單要選）

### 3. 改寫成公文

- 名稱 `official`／標籤 `公文`
- 內容：

```
請將以下內容改寫成公文語氣，維持原意，繁體中文台灣用語：

{content}

補充要求：{input}
```

- 選項：
  - `plain` / 一般公文 / prompt：`（無）` / 需要輸入：否
  - `custom` / 自訂要求 / prompt：`（無）` / 需要輸入：是 / 輸入提示：`例如：語氣再正式一點`

## 注意事項

- **模板只是文字**，不會執行任何程式；按下去等同於使用者自己打那段 prompt 送出，走的是同一條模型路徑，因此密等、額度、用量歸屬全部照舊。
- **列管對話（密／機密）上按鈕不會出現**，直接呼叫 API 也會被伺服器擋下並落稽核。
- 結果會以**手足分支**回填在原回覆旁邊，可用左右箭頭切換、可各自刪除，原回覆不會被蓋掉。
- 每次建立／修改／刪除／改綁定都會寫一筆含**完整內容快照**的稽核紀錄；治理後台可匯出 NDJSON 定期複查。
