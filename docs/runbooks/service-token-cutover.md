# 服務憑證切換（已完成，退役）

這份說明已經完成，不再是操作步驟。不要照舊版步驟做。

共用的 `CSP_SERVICE_TOKEN` 與 `CSP_BOOTSTRAP_TOKEN` 已退役。各服務只讀自己的 `ANILA_SERVICE_TOKEN_FILE`。這兩個名字不是設定欄位，compose 也不會把它們傳進容器。

資料庫裡 `is_legacy` 的服務客戶端列不是身分。自動核發會換掉這種列，而且不把舊祕密留成寬限憑證。

`.env` 或 shell 裡這兩個鍵有非空值時，部署拒絕，訊息只印鍵名。程序環境裡還看得到非空值時，該服務拒絕啟動，請從 `.env` 刪掉那一行。
