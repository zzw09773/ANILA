## 二、十分鐘:進內網跑三行(決定 P2.1 長什麼樣)

**在 agent 程式實際跑的那個 Lab 裡面跑**,不是在 MLSteam 主機的 shell 上跑 —— 兩者的網路出口可能不一樣。

```bash
curl -s  -o /dev/null -w "門面帶驗證: %{http_code}\n" https://anila.ai.ncsist.org.tw/
curl -s  -o /dev/null -w "jwks帶驗證: %{http_code}\n" https://anila.ai.ncsist.org.tw/.well-known/jwks.json
curl -sk -o /dev/null -w "jwks略驗證: %{http_code}\n" https://anila.ai.ncsist.org.tw/.well-known/jwks.json
```

| 結果 | 意思 | 影響 |
|---|---|---|
| 403 | nginx 的隱藏檔規則誤傷 `.well-known` | **一行設定**,最好的結果 |
| 帶驗證失敗、略過成功 | 那個 Lab 沒有 CSPKI 信任錨 | 把 `services/csp/app/services/cspki_ca_bundle.pem` 佈進去 |
| 兩個都連不出去 | agent 打不到 CSP | P2.1 要改走備案(釘死公鑰,失去自動輪替) |

**這三行決定 P2.1 的形狀,所以它排在其他事情前面。**
