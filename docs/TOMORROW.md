## 三、我今天講錯一件事，已更正

**「治理中心選的主路由模型，Router 收不到」——是錯的，你是對的。**

實測：用正式 API 把主路由換掉，trace 和用量紀錄都跟著換，換回來又變回去。

錯的原因是：程式裡有一段註解在**描述修好之前的狀態**，而它就寫在修正程式的正上方。
只讀那段註解就會得到相反的結論。已經在假控制項清單裡更正並記下這個誤判。
